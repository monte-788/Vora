Connect WebDAV

Works with or without folders. A file whose name contains something like "S01E02" or "1x02" (e.g. "Young Sheldon S01E02.mp4") is read as an episode — everything before that part becomes the show's title, and episodes with the same title are grouped into one show. A file with no such pattern is imported as a movie. Folders also work if you have them: each subfolder becomes a show (named after the folder), with video files inside — optionally organized into "Season 1", "Season 2", … — as its episodes.

Titles play from this server's address plus each file's path. Genre, banner, and description are auto-filled from TMDB when a key is set.

The username and password are stored only in this browser (not encrypted) so Vora can reconnect without asking again — skip them if your server doesn't need login, and avoid reusing an important password here.
